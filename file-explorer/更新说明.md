- 重命名
- 删除

**在空白区域：**
- 新建文件夹

- **图标视图**：大图标网格显示

## 使用方法

### 启动应用

```bash
cd file-explorer
npm install  # 如果还没有安装依赖
npm run dev
```

### 基本操作

1. **导航**
   - 使用工具栏的前进/后退/上一级按钮
   - 在地址栏输入路径
   - 双击文件夹进入

2. **文件操作**
   - 右键点击文件/文件夹打开菜单
   - 使用键盘快捷键
   - 在空白处右键新建文件夹

3. **切换视图**
   - 在每个面板标题栏点击"列表"或"图标"按钮
   - 每个面板可以有独立的视图模式

## 关于嵌入真实Windows资源管理器

技术说明：由于Electron的限制，无法直接嵌入Windows资源管理器的COM组件。我们采用了另一种方案：通过Electron的Node.js能力访问文件系统，用React构建了一个高度相似的用户界面，提供了几乎相同的体验，同时保持了Web技术栈的灵活性。

主要优势：
- 完全可定制的用户界面
- 跨平台兼容（虽然主要针对Windows）
- 无需Windows系统依赖
- 更好的开发和维护体验
